# به نام خدا — ردیابی افراد

برنامهٔ اندروید و سامانهٔ فارسی برای ارسال آخرین موقعیت با رضایت کاربر و مشاهدهٔ آن توسط مدیر.

## امکانات

- اندروید ۸ به بالا؛ درخواست مرحله‌ای مجوز مکان و الزام مجوز پس‌زمینه در نسخه‌هایی که این مجوز جداگانه دارند.
- نام و شماره موبایل بدون پیامک؛ شماره فقط برچسب شناسایی است و نقش رمز ورود ندارد. هر نصب، توکن مستقل دارد.
- رضایت صریح پیش از ثبت‌نام و ارسال. اعلان فعال با دکمهٔ توقف و امکان شروع دوباره با تأیید رضایت.
- دریافت مکان از GPS و شبکه، بدون نیاز به سرویس مکان‌یابی Google Play. درخواست موقعیت حدود هر ۱۵ ثانیه و ارسال مجدد آخرین نمونه حدود هر ۳۰ ثانیه؛ اندروید، دقت GPS، اینترنت و باتری بر زمان واقعی اثر دارند.
- توقف فوری ارسال روی گوشی؛ حذف موقعیت از پنل مدیر پس از دریافت درخواست لغو توسط سرور. اگر اینترنت قطع باشد، درخواست لغو ذخیره و پس از اتصال مجدداً ارسال می‌شود.
- نمایش موقعیت خود فرد حتی پس از توقف اشتراک، در زمان باز بودن برنامه.
- ورود مدیر با نام کاربری، رمز عبور و TOTP سازگار با Ente Auth؛ هیچ نشست مدیریتی قبل از تأیید هر دو مرحله ساخته نمی‌شود.
- نقشهٔ همهٔ افراد، جست‌وجو با شماره موبایل، نمایش زمان نمونه، دقت و باتری. پنل هر ۵ ثانیه به‌روز می‌شود و موقعیت قدیمی مشخص است.
- ذخیرهٔ فقط آخرین موقعیت؛ تاریخچهٔ حرکت ذخیره نمی‌شود.

## راه‌اندازی سامانه روی سرور

این مخزن سرویس میزبانی نیست. برای کار بین گوشی‌های مختلف باید سرور روی یک آدرس HTTPS قابل دسترس اجرا شود. هیچ دامنه یا سرور فعالی داخل مخزن اولیه وجود نداشت؛ APK عمومی یک فیلد «آدرس سامانه» دارد. هیچ اطلاعات ورود، کلید TOTP یا موقعیت واقعی در کد قرار داده نشده است.

روش پیشنهادی برای یک سرور لینوکسی با Docker Compose:

1. دامنه را به IP سرور وصل کنید و پورت‌های ۸۰ و ۴۴۳ را باز بگذارید.
2. `.env.example` را به `.env` کپی و `DOMAIN` را تنظیم کنید. فایل `.env` را وارد Git نکنید.
3. اجرا کنید:

```sh
docker compose up -d --build
docker compose logs server
```

4. در اولین اجرا، خروجی سرور یک `ADMIN SETUP TOKEN` خصوصی نشان می‌دهد. آن را در صفحهٔ راه‌اندازی وب وارد کنید، نام کاربری و رمز عبور دست‌کم ۱۲ نویسه‌ای انتخاب کنید.
5. کلید TOTP نمایش‌داده‌شده را به‌صورت دستی در Ente Auth اضافه کنید: نوع TOTP، الگوریتم SHA1، ۶ رقم، ۳۰ ثانیه و نام حساب Radyabi. کد آن را در پنل تأیید کنید. راه‌اندازی مجدد حساب مدیر از طریق وب پس از این مرحله بسته می‌شود.
6. در ورودهای بعدی، نام کاربری و رمز عبور و سپس کد Ente Auth لازم است. کد استفاده‌شده دوباره پذیرفته نمی‌شود؛ پس از راه‌اندازی، برای ورود منتظر کد بعدی باشید.
7. همین آدرس HTTPS را در APK وارد کنید. در ساخت اختصاصی می‌توان `-PserverUrl=https://your-domain` را داد تا از قبل در برنامه نوشته شود.

Caddy گواهی HTTPS را تهیه می‌کند. پایگاه SQLite و کلید رمزگذاری در volume خصوصی `tracker-data` ذخیره می‌شوند. از کل volume با هم پشتیبان بگیرید؛ کلید `server.key` برای خواندن TOTP لازم است. ساعت سرور باید همگام باشد. خروجی حاوی کلید راه‌اندازی را منتشر نکنید.

## اجرای محلی و آزمایش

Node.js 24 یا بالاتر، بدون وابستگی npm برای API:

```sh
node server/scripts/fetch-vendor.mjs
npm test --prefix server
node server/src.mjs
```

پنل محلی روی `http://127.0.0.1:3000` است. APK عمداً HTTP بدون رمزگذاری را نمی‌پذیرد. برای اتصال گوشی از HTTPS استفاده کنید. راه‌اندازی Docker در حالت production مقدار `PUBLIC_ORIGIN` را تنظیم می‌کند.

## ساخت اندروید

JDK 17، Gradle 8.9، Android SDK 35 و Build Tools 35 لازم است:

```sh
cd android
gradle :app:assembleDebug :app:lintDebug
```

خروجی آزمایشی: `android/app/build/outputs/apk/debug/app-debug.apk`. کلید آزمایشی برای انتشار نهایی استفاده نشود. GitHub Actions همراه آزمون‌های API، نسخهٔ release بدون امضا و Android lint را می‌سازد؛ آن خروجی پیش از نصب باید با کلید خصوصی امضا شود.

برای خروجی نهایی، keystore خصوصی خود را با متغیرهای `TRACKER_KEYSTORE`، `TRACKER_STORE_PASSWORD`، `TRACKER_KEY_ALIAS` و `TRACKER_KEY_PASSWORD` معرفی و `:app:assembleRelease` را اجرا کنید. کلید امضای APK تحویل‌شده در مخزن عمومی ذخیره نمی‌شود. برای به‌روزرسانی همان نصب باید همان کلید امضا و versionCode بالاتر استفاده شوند.

## رفتار و محدودیت‌های اجرایی

- دسترسی «همیشه» مجوزی قابل لغو است؛ ردیابی مخفی یا اجبار کاربر وجود ندارد.
- اگر برنامه force-stop شود، سیستم گوشی را خاموش کند، GPS خاموش باشد یا اینترنت قطع شود، موقعیت لحظه‌ای تضمین نمی‌شود. پس از force-stop کاربر باید برنامه را دوباره باز کند. پس از روشن‌شدن گوشی، ادامهٔ ارسال فقط با رضایت ذخیره‌شده و مجوز معتبر تلاش می‌شود.
- Android 13 به بالا ممکن است اجازهٔ اعلان را بخواهد؛ در صورت رد آن، سیستم فعالیت سرویس را در بخش برنامه‌های فعال نمایش می‌دهد.
- هر نصب مستقل است. دو نصب با یک شماره، دو دستگاه جدا هستند؛ داشتن شمارهٔ فرد دیگر اجازهٔ دسترسی به موقعیت او نمی‌دهد.
- ثبت‌نام بدون پیامک طبق درخواست باز است؛ شماره هویت تأییدشده محسوب نمی‌شود. مدیر باید نام و شمارهٔ افراد شناخته‌شده را بررسی کند.
- به علت نگهداری فقط آخرین نمونه، پس از قطع اینترنت فقط آخرین موقعیت ذخیره‌شده ارسال می‌شود؛ نمونهٔ قدیمی‌تر موقعیت جدیدتر را جایگزین نمی‌کند.
- سرور نمونه، محدودیت تعداد تلاش برای ورود و ثبت‌نام دارد. پشت پروکسی، IP اتصال ملاک است و هدر دلخواه کاربر به‌عنوان IP واقعی پذیرفته نمی‌شود.
- نقشه از OpenFreeMap و داده‌های OpenStreetMap است. کتابخانه‌های مرورگر به صورت محلی با checksum ثابت دریافت می‌شوند؛ دانلود نقشه همچنان به اینترنت نیاز دارد.
